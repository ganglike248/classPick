# 아래 경로들은 앱 흐름(설정 → 로그인 대기 → 수강신청) 안에서 localStorage에
# 저장된 상태를 이어받아야만 실제 콘텐츠가 그려진다. 크롤러(Googlebot,
# Mediapartners-Google 포함)는 항상 그 이전 단계를 거치지 않고 URL에 콜드로
# 접속하므로, 이 경로들은 크롤러 입장에서 영원히 "콘텐츠 없음 → 안내문 잠깐
# 표시 → 홈으로 리디렉션"만 보게 된다. 실제 사용자는 앱 내부 이동으로만
# 도달하므로 광고 노출에는 영향이 없고, robots.txt는 봇에게만 적용된다.
#
# /register, /result: 상태 없이 접속하면 즉시 "/"로 리디렉션됨 (RegisterPage,
#   ResultPage 참고) — 애드센스 정책의 "콘텐츠가 없는 화면", "알림·이동·기타
#   행동 목적으로 사용되는 화면"에 정확히 해당해 심사 반려의 원인이 됨.
# /feedback: 일반 방문자를 위한 콘텐츠가 아니라 운영자 전용 관리 화면(비밀번호
#   로그인 후 피드백/랭킹 관리).
User-agent: *
Disallow: /register
Disallow: /result
Disallow: /feedback
